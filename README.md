- 로컬 스크립트가 보고서 HTML을 생성 → 탭 하나로 병합 → 전체 암호화 → 이 저장소로 push
- GitHub Pages가 고정 URL로 서빙: **https://bapzzi.github.io/report/**
- 본문은 암호로 보호됩니다. 공개되어 있는 것은 암호화된 산출물뿐입니다

이 저장소는 발행 결과물만 담습니다 — 생성 로직은 별도의 비공개 저장소에 있습니다.

> 개인 도구입니다. 포트폴리오 성격의 프로젝트는 프로필의 고정 저장소를 참고해 주세요.
